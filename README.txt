ACCENTLIVE PRO

A) EXE BANANA (GitHub, jaise APK banate hain)
   1. Is zip ki saari files (andar ka .github folder samet) ek nayi GitHub repo mein upload karein.
   2. Actions tab -> "Build AccentLivePro" -> Run workflow. 10-15 minute lagte hain.
   3. Artifact "AccentLivePro-windows" download karke unzip karein. Is folder mein SAB kuch hai
      (exe, voice model, speech model). Python ya kuch aur install nahi karna.
   4. AccentLivePro.exe double-click karein.

B) EK BAAR KA ZAROORI DRIVER
   Chrome, Eyebeam, Google Voice jaise sab apps tak awaaz pahunchane ke liye Windows ko ek
   "virtual microphone" chahiye. Ye sirf driver se banta hai, exe ke andar nahi aa sakta.
   VB-Cable (free, vb-audio.com/Cable) ek baar install karke PC restart karein. Bas.

C) USE
   - Name aur Company likhein, "Hear it myself on" mein apna headset chunein, Save settings.
     (Virtual cable app khud chun leta hai.)
   - Dialer ya Chrome ke microphone mein "CABLE Output" chunein.
   - Start call: pehle naam, company aur AI voice wali line bolti hai.
   - Button ya 1-9 keys. Ek press = ek baar. Esc = Stop.

Agar build fail ho to Actions ka error log bhej dein.
